# 🔁 AI Lab 2 – Control Structures

This lab was all about learning how to control the flow of a Python program using `if`, `elif`, `else`, and different kinds of loops.

Instead of just writing plain theory, I tried to understand and apply each concept step by step using simple examples and exercises. Everything was done in **Jupyter Notebook**, and pushed here for learning reference 💡

---

## 🧠 What I Learned

This lab focused on two main things:

### 🔹 Conditional Statements
These are used to make decisions in code:
- `if`: checks a condition and runs a block if it’s true
- `elif`: lets you check more conditions if the first one didn’t pass
- `else`: runs if nothing above matched

Also explored logical operators like:
- `and`: both conditions must be true  
- `or`: at least one needs to be true  
- `not`: flips the condition around 🙃

### 🔹 Loops
These help repeat actions without writing the same code 100 times (thank god 🙏):
- `for` loop: goes through a range or list  
- `while` loop: runs as long as the condition is true  
- `nested` loops: when you’re feeling *extra* and want loops inside loops 🌀
